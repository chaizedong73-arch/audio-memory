# 录音记忆 / Audio Memory

一个正在开发中的课堂音频与资料工作台：采集音频并转写，关联课堂 PPT 画面与 OCR，通过本地材料接口向外部 AI 提供资料。这个仓库用于展示项目当前的技术实现和开发进度，**不是已验收的正式版**。

## 已实现的方向

- 录音分段、本地 Whisper 与可配置云端音频转写（火山方舟音频对话、OpenAI 兼容语音转写协议）。
- 字幕查看、修订及材料接口；情景按时间、地点、人物、起因、经过、结果组织。
- 上课模式通过手机采集 PPT 画面并 OCR；目标是不保存课堂录像。
- Electron 桌面界面、Python 功能模块及本地材料索引。

## 当前状态

已进行模块测试、合成音频/视频测试及部分真实服务调用。真实手机课堂采集、连续转写质量、故障恢复、跨电脑安装和笔记 AI 联调尚未完成验收；部分旧功能仍在迁移。云端服务兼容性取决于供应商实际支持的音频协议。项目可能存在已知问题，请勿把当前源码作为生产环境成品。

## 开发运行（Windows）

需要 Python 3.13、Node.js 和 npm。源码目录执行 `install.cmd` 安装 Python 核心依赖；在 `desktop` 目录执行 `npm ci`、`npm run build`、`npm start`。模型首次使用可能需要联网下载；云端模式需要用户自行配置支持音频的服务及密钥。依赖版本和跨电脑运行仍待验证。

此展示仓库不包含个人录音、字幕、API 密钥、模型权重、Python 运行环境、Node 依赖或构建产物。USB 手机连接需要另行准备 Android Platform Tools；安装包构建配置还依赖本地构建目录，目前不能直接复现完整安装包。

## 结构

- `desktop/`：Electron 桌面界面和服务管理。
- 根目录 Python 文件：录音、转写、材料网关、视觉处理及测试。
- `scene/`：手机采集页面。
- `installer/`：仍在开发中的 Windows 打包脚本。
- `toolbox-module/`：早期工具箱模组源码，依赖宿主环境。
