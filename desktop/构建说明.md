# 桌面构建说明 〔GPT·11-09 10:08〕

在 `desktop` 目录安装 Node 依赖后执行 `npm run build`，再执行 `npx electron-builder --win --dir --x64 --config electron-builder.yml`。输出为项目内 `build/electron/win-unpacked`。〔GPT·11-09 10:08〕

构建前需准备 `build/runtime`（Windows Python 运行环境及 `requirements-core.txt`、`requirements-vision.txt` 依赖）和 `build/model/base`（Whisper base 模型）。`installer/build-runtime.ps1` 展示了运行环境构建过程及模型 SHA-256 校验；其原流程还需 Inno Setup。手机连接所需平台工具及 cloudflared 应由各自官方渠道获取并保留随附许可文件。运行环境、模型、二进制文件和用户资料不纳入源代码仓库。〔GPT·11-09 10:08〕

当前电脑已用准备好的本地运行环境和模型构建，并启动打包程序验证资料网关连接与关闭；未在新电脑验证从零准备全部构建依赖。〔GPT·11-09 10:08〕
